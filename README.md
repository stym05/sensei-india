# Sensei India Website

A responsive ed-tech/coaching website built with Next.js App Router and Tailwind CSS. It includes tutor search, course discovery, student registration UI, contact form, Privacy Policy, and Terms & Conditions pages.

## Run in VS Code

1. Open this folder in VS Code.
2. Run `npm install` in the terminal.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Main Features

- Tutor search with subject/location/mode filters
- Student registration form for course/training interest
- Responsive landing page with interactive cards and CTAs
- Course catalog and tutor listing pages
- Required information pages: Contact, Privacy Policy, Terms & Conditions
- Easy-to-customize content in `data/site.ts`

## Customize

Edit `data/site.ts` to update coaching name, courses, tutors, pricing, phone number, email, address, and FAQs.
